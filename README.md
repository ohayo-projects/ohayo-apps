# ohayo-apps

Product site for the Ohayo apps, served at **`https://apps.ohayo.by`** from Cloudflare
(Workers Assets). Sibling of [`ohayo-legal`](https://github.com/ohayo-projects/ohayo-legal),
which serves the legal/support documents at `legal.ohayo.by` — keep the two in step: the
landing links out to `legal.ohayo.by/network/{support,privacy,eula}`.

**The repo root is the deploy root** (`wrangler.jsonc` → `assets.directory: "."`), so every
file here is reachable at `apps.ohayo.by/<path>` unless it is listed in
[`.assetsignore`](.assetsignore) — the templates, `render.py` and this README are.
**Anything new that is not part of the public site must be added to `.assetsignore`.**
(A `_redirects` file cannot help: Workers Assets only accepts 200/301/302/303/307/308
there, so a 404 rule fails the whole deploy.)

```
index.html                  → apps.ohayo.by/                    hub, English      (generated)
ru/index.html               → apps.ohayo.by/ru                  hub, Russian      (generated)
ohayo-network/index.html    → apps.ohayo.by/ohayo-network        landing, English  (generated)
ohayo-network/ru/index.html → apps.ohayo.by/ohayo-network/ru     landing, Russian  (generated)
404.html                    → served for unknown paths
robots.txt, sitemap.xml     → sitemap is generated by render.py
_headers                    → CSP, nosniff, referrer policy, immutable cache for /assets/*
assets/                     → stylesheet, scripts, icon, Apple badges, screenshots, OG image

templates/*.tmpl.html       ← page structure, one per page type   (not served)
render.py                   ← structure + copy → the four pages   (not served)
```

## Editing

Never hand-edit the generated `*.html`. Copy for **both locales** lives in `STRINGS` in
[`render.py`](render.py); structure lives in `templates/`. Then:

```sh
python3 render.py     # rewrites the four pages + sitemap.xml, and fails loudly on an
                      # unfilled {{PLACEHOLDER}} in any locale
```

Preview locally (the pages use absolute `/assets/…` paths, so serve from the repo root):

```sh
python3 -m http.server 8899
open http://localhost:8899/ohayo-network/
```

## Languages

English is canonical (`/ohayo-network`), Russian lives at `/ohayo-network/ru`, and each
page declares both with `<link rel="alternate" hreflang>` plus `x-default` → English.
[`assets/head.js`](assets/head.js) runs before paint and sends a **first-time** visitor
whose `navigator.language` is Russian to the ru page, by pathname, so preview deployments
stay on their own origin. Clicking EN/RU stores `ohayo.lang` in `localStorage` and the
redirect never fires again. Only the English pages redirect — a loop is impossible.

## Assets

- `assets/badge-mas-en-us.svg`, `assets/badge-mas-ru-ru.svg` — **Apple's official**
  "Download on the Mac App Store" badges from Apple Marketing Resources. Never recolour,
  crop, or rebuild them, and keep the locale matched to the page.
- `assets/ohayo-network/{en,ru}/*.png` — the same captures used for the App Store
  screenshots, taken from `dist/screenshots/raw/<locale>/` in the Ohayo Network repo and
  downscaled for the web. Personal data (public IP, MAC, SSID) is pixelated in the capture
  itself. Re-shoot there, re-copy here.
- `assets/ohayo-network/og.png` — 1200×630 social card, composed from the app icon and the
  popover capture.
- `assets/ohayo-network/icon.svg` — the **app** icon artwork (`OhayoNetwork.icon`), with
  Apple's 92px canvas padding trimmed off via the `viewBox`. It is the app's, so it only
  appears on the app's own pages and on its card — never in the hub chrome or as the
  favicon of a page that is not about that app.
- `assets/mark.svg` + `assets/apple-touch-icon.png` — the **studio** mark (a sun over the
  horizon: *ohayo* = good morning), used by the hub and the 404 page.

No web fonts, no analytics, no third-party requests of any kind — the site makes the same
promise the app does, and the CSP in `_headers` enforces it (`default-src 'self'`).

## Deploy — Cloudflare

Same setup as `ohayo-legal`: Workers & Pages → connect this GitHub repo, no build command,
output directory `/` (root); every push to `main` redeploys. The worker is named `apps`
in [`wrangler.jsonc`](wrangler.jsonc); attach the custom domain `apps.ohayo.by` under the
project's **Domains** tab (DNS and SSL are automatic, `ohayo.by` is on the same account).

Clean URLs are on: `foo.html` is served at `/foo`, and a directory's `index.html` at the
directory path — which is why the pages sit at `ohayo-network/index.html` rather than
`ohayo-network.html`.

## Adding an app

Add a card to `templates/home.tmpl.html` and its copy to `STRINGS` (both locales), then
create `templates/<slug>.tmpl.html` plus an entry in `PAGES` and `LOCALES` output paths in
`render.py`. Screenshots go to `assets/<slug>/<locale>/`. Re-run `python3 render.py`.

## Referenced by

Ohayo Network's App Store listing uses `legal.ohayo.by` for its Support and Privacy URLs;
this site is the **Marketing URL** candidate (`https://apps.ohayo.by/ohayo-network`).
Do not break a URL once it is published — App Store Connect rejects dead links.
